# data/samples

Déposer ici les fichiers d'entrée réels (ex. `JUIN - Produits à bencher.xlsx`).

**Ces fichiers ne sont pas versionnés** (voir `.gitignore`) : ils peuvent contenir des données
d'entreprise. Seuls ce README et `.gitkeep` sont suivis par Git.

Pour des données de test partageables et versionnées, utiliser `data/fixtures/`.
